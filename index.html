    O que é a Visão Ensemble?

    O Ensemble ECMWF executa 51 simulações meteorológicas em paralelo, variando levemente as condições iniciais para medir incertezas na previsão do tempo.

    A previsão base é determinística, serve como informação inicial para o dia, mas recomendamos verificar os avisos para acessar alguma informação extra que merece atenção (se houver).

    Cada aviso é gerado apenas quando pelo menos 25% dos membros concordam com condiçoes que merecem mais atenção.

    Se não houver concordância mínima de 25%, consideramos a não geração de aviso, o que sugere alguma incerteza da previsão base.
